# Support

For setup problems, feature questions, and non-sensitive bugs, open a GitHub
issue using the appropriate template. Include your operating system, Node and
Docker versions, the command you ran, and sanitized logs from
`.moonestates/dev.log`.

Never attach `.env` files, `.moonestates/`, database exports, credentials,
customer information, or unsanitized provider responses.

Security vulnerabilities must be reported privately as described in
[SECURITY.md](SECURITY.md).
